# Glim Demo

This is a zero-backend hackathon prototype for a women-safety app. It demonstrates:

- timed protection mode
- fake incoming calls
- safety response countdown
- emergency contact escalation
- contact-app alarm state
- private browser microphone buffering
- simulated cloud upload only after SOS escalation
- live-location fallback

## Run

The AI "mum" call needs the Node backend (it holds the Anthropic API key — never put the key in `app.js`):

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm install
npm start
```

Then open:

```text
http://localhost:4173
```

UI-only (no AI mum call) still works with any static server — the fake call falls back to canned lines:

```bash
python3 -m http.server 4173
```

## Mum mockup call API

`POST /api/mum-call` returns the next spoken line for the fake companion call, generated by Claude (`claude-opus-4-8`) playing a calm, reassuring mum.

```jsonc
// request
{ "caller": "Mom", "event": "answered", "spoken": ["...prior lines this call..."] }
// response
{ "reply": "Hi sweetheart, I'm right here — keep walking and stay on with me." }
```

The client ([app.js](app.js)) calls this each time the mum speaks during an active call and falls back to the static `prompts` list if the backend is unreachable.

## Vapi safe-word tool

When the live Vapi "Mummy" call is used, the agent detects the predefined safe word and calls a `trigger_safety_flag` tool. Two endpoints handle that:

- `POST /vapi/tools` — give this URL to Vapi as the tool's server URL. Receives the tool call, records the flag, and replies in Vapi's `{ results: [{ toolCallId, result }] }` format. Optionally set `VAPI_SERVER_SECRET` and the matching secret in Vapi to verify the `x-vapi-secret` header.
- `GET /api/safety-flag` — the app polls this while walking mode is on. Returns `{ flag: 1, safeWordHeard, callId, at }` once (consume-once), then `{ flag: 0 }`. On `flag: 1` the app escalates to trusted contacts.

Local dev: Vapi must reach `/vapi/tools` over public HTTPS — tunnel with `ngrok http 4173` and use the `https://…ngrok…/vapi/tools` URL.

## Demo Script

1. Press `Start walk`.
2. Wait for the check-in timer or press `Fake call`.
3. Press the green call button to show the fake companion call.
4. Repeat and press the red call button to trigger the safety countdown.
5. Let the countdown finish to notify contacts and upload the private audio buffer.
6. Use `Settings` to tune the timers, auto-recording, fake call, contact-app alarm, and disguise mode.

## Privacy Model In This Demo

- When walking mode starts, audio is buffered locally in browser memory.
- Pressing `I'm safe` stops recording and discards the local buffer.
- Nothing is uploaded during normal safe check-ins.
- If SOS/emergency escalation happens, buffered chunks and new chunks move into the simulated cloud stream.
- This demo has no real cloud endpoint; `Cloud stream` is only an on-screen simulation.

## Production Next Steps
